Windows

Windows 10 or later, 64-bit. Two installers, same app: the .msi is the standard choice; the setup .exe is a smaller wizard-style installer.

Install

  1. Double-click the downloaded .msi and follow the installer.
  2. If SmartScreen says "Windows protected your PC", click More info, then Run anyway.
  3. Open Track2Mix from the Start menu.
This build isn't code-signed yet, so the SmartScreen warning is expected. It goes away as the release builds reputation.

Debian / Ubuntu

64-bit (amd64). Needs WebKitGTK 4.1, which ships with Ubuntu 22.04 and Debian 12 or newer, plus Mint, Pop!_OS and other derivatives.

Download .debTrack2Mix_0.1.0_amd64.deb 5.0 MB

Install

  1. Open a terminal in the folder you downloaded to and install with apt. It fetches any missing libraries for you. sudo apt install ./Track2Mix_0.1.0_amd64.deb
  2. Launch Track2Mix from your applications menu.

Arch Linux

x86_64 pacman package. Installs the desktop app and the track2mix command-line tool. Works on Arch and its derivatives (EndeavourOS, Manjaro, Omarchy).

Download .pkg.tar.zsttrack2mix-0.1.0-1-x86_64.pkg.tar.zst 6.4 MB PKGBUILDBuild it yourself with makepkg

Install

  1. Install the package with pacman, which pulls in WebKitGTK and the other dependencies. sudo pacman -U ./track2mix-0.1.0-1-x86_64.pkg.tar.zst
  2. Launch Track2Mix from your app launcher, or run track2mix-desktop.
  3. Prefer to build from source? Put the PKGBUILD in an empty folder and run: makepkg -si

First run

From Rekordbox to a ranked shortlist in five steps

The same on every system. Track2Mix only reads the XML you export; your collection file and audio are never modified.

01

Export your collection

In Rekordbox choose File → Export Collection in xml format and save it somewhere easy to find.

02

Point Track2Mix at it

Open the app and choose that XML file.

03

Check coverage first

A dry run reports how many tracks resolve to real files (moved drives and streaming stubs don't) before a long analysis.

track2mix analyze --xml ~/rekordbox.xml --dry-run
04

Run the analysis

It uses every CPU core. Results land in library.db, a single SQLite file you own and can delete.

05

Pick and export

Click any track to see its compatible neighbours, ranked. Tick the ones you want and export an M3U8; Rekordbox imports it directly.

TIP

Drive moved?

Remap paths without re-tagging anything; only newly found tracks get decoded.

track2mix analyze --xml ~/rekordbox.xml \ --path-map '/old/music=/new/music' \ --skip-analyzed

Verify your download

Check it's the file we built

Every release publishes a SHA256SUMS file. Put it next to your download and run:

Linux

sha256sum -c SHA256SUMS --ignore-missing

Windows (PowerShell): compare the hash to the matching line

Get-FileHash .\Track2Mix_0.1.0_x64_en-US.msi

Common questions

A lot of tracks failed to analyse

Usually a moved drive (use --path-map), streaming entries that were never local files, or DRM-protected iTunes M4As.

A track has no key

Track2Mix uses Rekordbox's own key analysis, so results match your CDJs. Analyse the track in Rekordbox and re-export.

Does it change my Rekordbox library?

No. It reads the exported XML and writes only M3U8 playlists and its own database.
