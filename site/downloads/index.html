First run

  1. In Rekordbox: File → Export Collection in xml format.
  2. Open Track2Mix and point it at that XML file.
  3. Run the analysis. Results go to library.db, a single file you own.
  4. Click any track for its ranked compatible neighbours, then export an M3U8 for Rekordbox.

If your OS warns you

macOS: builds that aren't notarized yet show "developer cannot be verified". Right-click the app, choose Open, then Open again. Once is enough.

Windows: SmartScreen may say "protected your PC". Click More info → Run anyway.

Full install notes

Verify a download

Each release includes a SHA256SUMS file. Put it next to the files you downloaded and run:

sha256sum -c SHA256SUMS

All builds and releases are on GitHub, and the source is there too.
