Install.

Windows

Windows 10 or later, 64-bit. The .msi is the standard installer; the setup .exe is the same app in a smaller wrapper.

  1. Double-click the downloaded .msi and follow the installer.
  2. If SmartScreen says “Windows protected your PC”, click More info, then Run anyway. This build is not code-signed yet, so the warning is expected; it fades as the release builds reputation.
  3. Open Track2Mix from the Start menu.

Debian, Ubuntu

64-bit. Needs WebKitGTK 4.1, which ships with Ubuntu 22.04 and Debian 12 or newer, Mint, Pop!_OS and their relatives.

  1. Open a terminal in the folder you downloaded to and install with apt, which fetches any missing libraries.
    sudo apt install ./Track2Mix_0.1.0_amd64.deb
  2. Launch Track2Mix from your applications menu.

Arch

x86_64 package. Installs the desktop app and the track2mix command-line tool.

  1. Install with pacman, which pulls in WebKitGTK and the other dependencies.
    sudo pacman -U ./track2mix-0.1.0-1-x86_64.pkg.tar.zst
  2. Launch Track2Mix from your app launcher, or run track2mix-desktop.
  3. Prefer to build from source? Put the PKGBUILD in an empty folder and run makepkg.
    makepkg -si

Any other Linux

The AppImage bundles its own audio stack, so it runs on a distro you can’t install packages into.

  1. Make the file executable and run it.
    chmod +x Track2Mix-*.AppImage
./Track2Mix-*.AppImage

Verify the file

Check that what you downloaded is what we built.

  1. On Linux, with SHA256SUMS in the same folder:
    sha256sum -c SHA256SUMS --ignore-missing
  2. On Windows, in PowerShell, compare the hash to the matching line of SHA256SUMS:
    Get-FileHash .\Track2Mix_0.1.0_x64_en-US.msi

First run, in five steps.

  1. Export your collection. In Rekordbox: File, then Export Collection in xml format. That file is the only thing Track2Mix needs.
  2. Open Track2Mix and import the XML. It resolves which entries are real files on disk and reports the rest before anything is decoded.
  3. Let it listen. Every core is used. Three 30-second stretches per track, four signals, one energy number. Results land in one library.db you own.
  4. Leave skip analysed on. The next import only decodes tracks it hasn’t seen, so a growing library costs minutes, not an evening.
  5. Dig, build, blend. Click any track for its ranked neighbours, press play to audition, tick the keepers, order them in Playlist and export the M3U8, or blend them in Compose.

Drive moved?

Remap paths without re-tagging anything; only newly found tracks get decoded.

track2mix analyze --xml ~/rekordbox.xml \
  --path-map '/old/music=/new/music' \
  --skip-analyzed

Many tracks failed?

Usually a moved drive, streaming entries that were never local files, or DRM-protected M4A from iTunes. The import report names each one.

A track has no key?

Keys come from Rekordbox’s own analysis so they match your CDJs. Analyse it there and re-export.
