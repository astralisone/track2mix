Windows

Windows 10 or later, 64-bit. Two installers, same app: the .msi is the standard choice; the setup .exe is a smaller wizard-style installer.

Install

  1. Double-click the downloaded .msi and follow the installer.
  2. If SmartScreen says "Windows protected your PC", click More info, then Run anyway.
  3. Open Track2Mix from the Start menu.
This build isn't code-signed yet, so the SmartScreen warning is expected. It goes away as the release builds reputation.

Debian / Ubuntu

64-bit (amd64). Needs WebKitGTK 4.1, which ships with Ubuntu 22.04 and Debian 12 or newer, plus Mint, Pop!_OS and other derivatives. Other distributions: the AppImage runs anywhere and bundles GStreamer for the composer; Fedora and friends take the .rpm.

  1. Open a terminal in the folder you downloaded to and install with apt. It fetches any missing libraries for you. sudo apt install ./Track2Mix_0.1.0_amd64.deb
  2. Launch Track2Mix from your applications menu.

Arch Linux

x86_64 pacman package. Installs the desktop app and the track2mix command-line tool. Works on Arch and its derivatives (EndeavourOS, Manjaro, Omarchy).

Download .pkg.tar.zsttrack2mix-0.1.0-1-x86_64.pkg.tar.zst 6.4 MB PKGBUILDBuild it yourself with makepkg

Install

  1. Install the package with pacman, which pulls in WebKitGTK and the other dependencies. sudo pacman -U ./track2mix-0.1.0-1-x86_64.pkg.tar.zst
  2. Launch Track2Mix from your app launcher, or run track2mix-desktop.
  3. Prefer to build from source? Put the PKGBUILD in an empty folder and run: makepkg -si

Android tablets

The digging half of Track2Mix for a tablet in landscape: track table, filters, Camelot wheel, compatibility matching, playlist builder and M3U8 export, reading the library you analysed on your computer. A one-time purchase through the store — no subscription. Android 8+ tablets; not a phone app.

Google PlayStore link and current availability from $19.99

Set up

  1. Analyse your collection with the desktop app or the CLI (above). The result is one file, library.db.
  2. Copy it to the tablet — Files, Google Drive, a USB drive.
  3. Open the app, tap Open library.db and pick the file. It is copied into the app's own storage and opened.
Previewing audio and the composer need the audio files on the tablet; the database points at the paths they had on your computer, so tracks whose files aren't present say so individually.

First run

From Rekordbox to a ranked shortlist — and a rendered mix — in five steps

The same on every system. Track2Mix only reads the XML you export; your collection file and audio are never modified.

01

Export your collection

In Rekordbox choose File → Export Collection in xml format and save it somewhere easy to find.

02

Import it

Open the app, click Import Rekordbox XML and choose the file. The database is written next to it.

03

Watch the coverage

The import screen reports how many entries resolved to real files (moved drives and streaming stubs don't) and lists failures. For a check before decoding anything, the CLI has a dry run:

track2mix analyze --xml ~/rekordbox.xml --dry-run
04

Let it finish

It uses every CPU core. Results land in a single SQLite file you own and can delete; leave skip analyzed ticked so a re-import only decodes new tracks.

05

Dig, arrange, export

Click any track to see its compatible neighbours, ranked; press play to audition. Tick the ones you want, open Playlist to order them harmonically and export an M3U8 — Rekordbox imports it directly — or open Compose, hit Auto-arrange, and export the blend as MP3.

TIP

Drive moved?

Remap paths without re-tagging anything; only newly found tracks get decoded.

track2mix analyze --xml ~/rekordbox.xml \ --path-map '/old/music=/new/music' \ --skip-analyzed

Verify your download

Check it's the file we built

Every release publishes aSHA256SUMS file. Put it next to your download and run:

Linux

sha256sum -c SHA256SUMS --ignore-missing

Windows (PowerShell): compare the hash to the matching line

Get-FileHash .\Track2Mix_0.1.0_x64_en-US.msi

Common questions

A lot of tracks failed to analyse

Usually a moved drive (use --path-map), streaming entries that were never local files, or DRM-protected iTunes M4As.

A track has no key

Track2Mix uses Rekordbox's own key analysis, so results match your CDJs. Analyse the track in Rekordbox and re-export.

Does it change my Rekordbox library?

No. It reads the exported XML and writes only the playlists, project files and renders you export, plus its own database.
